# Calculadora Simples

Projeto de calculadora web para praticar Git, GitHub, Issues e Pull Requests.

## Como executar

Abra o arquivo `index.html` no navegador. Não precisa instalar dependências.

## Funcionalidades

- Soma, subtração, multiplicação e divisão
- Botão de limpar e apagar último dígito
- Tratamento de divisão por zero
- Layout responsivo

## Melhoria sugerida para uma Issue

Adicionar suporte ao teclado físico do computador para digitar números, operadores, Enter (=), Backspace e Esc (limpar).

**Importante:** esta melhoria não está implementada na versão inicial. Faça-a em uma branch separada e abra um Pull Request para registrar a contribuição.
